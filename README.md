# Эмулятор языка оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление»
(ИКБО-41-25, Вариант №13). Практическая работа №1, Этап 1 (REPL).

## 1. Общее описание

Приложение эмулирует работу в командной строке UNIX-подобной ОС.
На этапе 1 реализован минимальный прототип с графическим
интерфейсом (GUI): пользователь вводит команды в строку ввода,
эмулятор разбирает их и выводит результат в область вывода.
Большинство команд на этом этапе являются заглушками.

## 2. Описание всех функций и настроек

- Графический интерфейс — окно с областью вывода и строкой ввода.
  Заголовок окна содержит имя VFS: `MyVFS`.
- Парсер (`emulator.parser.parse_line`) — разбивает строку
  на команду и аргументы, корректно обрабатывая аргументы в кавычках
  (например, `cd "My Documents"` распознаётся как один аргумент).
- Команды-заглушки (`emulator.commands`):
  - `ls [аргументы]` — выводит имя команды и аргументы;
  - `cd [аргументы]` — выводит имя команды и аргументы;
  - `exit` — завершает работу приложения, не принимает аргументов.
- Обработка ошибок — неизвестная команда или неверные аргументы
  выводят сообщение вида `ошибка: неизвестная команда: ...`,
  приложение при этом не завершается.

## 3. Описание команд для сборки проекта и запуска тестов

Зависимости, кроме стандартной библиотеки Python (tkinter),
не требуются.

Запуск приложения:

    python main.py

## 4. Примеры использования

После запуска открывается окно с заголовком `MyVFS`.
Примеры ввода в строке команд:

    $ ls -la /tmp
    ls -la /tmp

    $ cd "My Documents"
    cd My Documents

    $ qwerty
    ошибка: неизвестная команда: qwerty

    $ exit

После команды `exit` окно закрывается.
