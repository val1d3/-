# Эмулятор языка оболочки ОС

Практическая работа №1 по дисциплине «Конфигурационное управление»,
вариант 13 (группа ИКБО-41-25).

## 1. Общее описание

Эмулятор командной оболочки UNIX-подобной ОС с графическим окном
(tkinter). Работает в режиме REPL: пользователь вводит команду в
строку внизу окна и сразу видит результат в области вывода.

Особенности:

- заголовок окна равен имени виртуальной файловой системы (VFS),
  а без VFS заголовок `no-vfs`;
- VFS загружается из XML-файла и целиком хранится в памяти;
- команды можно выполнять из стартового скрипта, при этом ввод и вывод
  выглядят как обычный диалог с пользователем;
- ошибки (неверная команда, нет файла, плохой XML) выводятся как
  `ошибка: ...`, эмулятор продолжает работать.

Структура репозитория:

| Папка / файл | Назначение |
|---|---|
| `main.py` | точка входа |
| `src/emulator/` | исходный код эмулятора |
| `tests/` | модульные тесты |
| `vfs_examples/` | примеры VFS в формате XML |
| `startup_scripts/` | стартовые скрипты |
| `os_scripts/` | `.bat`-файлы для запуска проверок |
| `run.bat`, `run.sh` | запуск эмулятора |

## 2. Описание функций и настроек

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs-path ПУТЬ` | путь к XML-файлу с VFS |
| `--script ПУТЬ` | путь к стартовому скрипту (одна команда в строке) |

При запуске в окно выводятся все заданные параметры.

### Команды

| Команда | Описание |
|---|---|
| `ls [путь]` | показывает содержимое папки VFS (по умолчанию текущей), папки отмечены `/`; для файла выводит его имя |
| `cd [путь]` | меняет текущую папку; без аргумента переходит в корень; поддерживаются `.`, `..` и абсолютные пути вида `/home` |
| `uptime` | время работы эмулятора в формате `up ЧЧ:ММ:СС` |
| `tac файл...` | выводит строки файла (файлов) VFS в обратном порядке |
| `conf-dump` | выводит параметры запуска в формате `ключ=значение` |
| `exit` | завершает работу эмулятора |

Команды разбираются с учётом кавычек, например `tac "my file.txt"`.

Ошибки, которые обрабатываются:

- неизвестная команда, незакрытая кавычка;
- лишние или недостающие аргументы;
- `ls`, `cd`, `tac` без загруженной VFS;
- путь не найден, `cd` в файл, `tac` для папки или нетекстового файла;
- не найден или не читается скрипт, неверный XML в VFS.

### Формат VFS (XML)

```xml
<vfs name="DeepTreeVFS">
  <directory name="home">
    <file name="todo.txt">base64-содержимое</file>
  </directory>
</vfs>
```

Содержимое файла хранится в base64.

## 3. Команды для сборки, запуска и тестирования

Требуется Python 3.10 или новее. Внешних библиотек не нужно.

Запуск (Windows):

    .\run.bat
    .\run.bat --vfs-path vfs_examples/deep_tree.xml
    .\run.bat --script startup_scripts/stage4_demo.txt
    .\run.bat --vfs-path vfs_examples/deep_tree.xml --script startup_scripts/stage4_demo.txt

Запуск (Linux / macOS):

    ./run.sh --vfs-path vfs_examples/deep_tree.xml

Готовые проверки:

    .\os_scripts\test_stage4.bat
    .\os_scripts\test_stage4_no_vfs.bat

Модульные тесты:

    py -m unittest discover -s tests -v

## 4. Примеры использования

Запуск с VFS и скриптом:

    .\os_scripts\test_stage4.bat

Фрагмент диалога (VFS `DeepTreeVFS`):

    $ ls
    etc/
    home/
    $ cd home/user
    $ ls
    profile.txt
    projects/
    $ cd projects
    $ tac main.py
    print("Hello")
    $ cd /etc
    $ tac config.conf
    key=value
    $ cd
    $ uptime
    up 00:00:03

Обработка ошибок:

    $ ls nope
    ошибка: nope: нет такого файла или папки: nope
    $ cd etc/config.conf
    ошибка: etc/config.conf: не папка
    $ tac home
    ошибка: home: это папка
    $ tac
    ошибка: tac: не указан файл
    $ uptime 5
    ошибка: uptime: команда не принимает аргументов

Без VFS:

    $ ls
    ошибка: VFS не загружена
